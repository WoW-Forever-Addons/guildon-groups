# Guildon: Groups

Part of Guildon: a group finder inside the guild, for WoW Forever.

- `/gng` opens the window, `/gng new` posts a request, `/gng dnd` switches the toasts off and on.
- Requests travel between the members who have this part (addon messages in the guild channel, no server).
- Options: the cog in the window or `/gng options`.
